# message_gen
간단한 텍스트 메시지 제너레이터

iOS Safari 웹앱용 텍스트 생성기입니다. 저장된 카드를 터치하면 텍스트가 출력되고 클립보드에 복사됩니다.

## 사용 방법

1. 이 폴더를 정적 서버로 서빙합니다 (예: `python3 -m http.server 8000`).
2. iPhone Safari에서 접속합니다.
3. 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 사용할 수 있습니다.
   - 클립보드 복사는 HTTPS 또는 localhost 환경에서 가장 안정적으로 동작합니다.

## 기능

- 텍스트 입력 후 저장 → 카드 목록에 추가 (브라우저 localStorage에 저장)
- 카드별 예약 시점 메모 저장 (예: 토요일 11:50)
- 카드 터치 → 전체 텍스트 출력 + 클립보드 자동 복사
- 카드의 ✕ 버튼으로 삭제
- 다크모드 지원, 세이프 에어리어 대응
